# Recursion Algorithms Project (Python)

This project is a comprehensive library of mathematical and logic functions implemented using **pure recursion**, developed during my studies at **The Hebrew University of Jerusalem**.

## Project Description

The goal of this project is to solve complex problems by breaking them down into smaller sub-problems without using iterative loops. It covers a wide range of applications, from basic arithmetic to classic algorithmic puzzles like the Tower of Hanoi.

## Files

* `ex7.py` – Contains recursive implementations for multiplication, string reversal, Tower of Hanoi, and 2D list comparisons.
* `ex7_helper.py` – Provides basic arithmetic and string manipulation primitives to support recursive calls.

## Technologies

* **Python 3**
* **Recursive Programming Paradigm**
* **Logarithmic Complexity Algorithms** (e.g., `log_mult`)

## What I Learned

* Mastering the **Base Case** and **Recursive Step** for various data types.
* Implementing classic algorithms like **Tower of Hanoi**.
* Handling deep recursion for structured data like **nested lists** and **deep copies**.
* Optimizing recursive math with **logarithmic approaches** to improve efficiency.
